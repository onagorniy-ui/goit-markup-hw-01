# goit-markup-hw-01

Домашнє завдання №1 з курсу верстки HTML/CSS (GoIT).

## Опис
Базова семантична розмітка сторінки WebStudio:
- Структура документа HTML5 (`<!doctype html>`, `<head>`, `<body>`)
- Семантичні теги: `<header>`, `<nav>`, `<address>`, `<ul>`, `<li>`, `<a>`
- Підключення стилів та валідна розмітка
